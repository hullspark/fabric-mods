# Death Point Marker（死亡地点マーカー）

Fabric 向けのクライアント専用 MOD。死亡すると、死亡地点までの方角・距離・
座標を画面上部に 1 行表示する。ドロップしたアイテムを回収しに戻るとき、
当てずっぽうで歩かなくて済む。

**AI 支援で作成**: 本 MOD のコードは AI（Claude）の支援で作成した。他
MOD のコードやアセットは一切流用していない。

## 機能

- サーバーがプレイヤーごとに保持しているバニラの `getLastDeathPos()`
  （回収コンパスが指す先と同じデータ）を読み取る。クライアント側の
  イベントから推測する方式ではないため、`doImmediateRespawn`（死亡画面
  を飛ばす設定）が有効でも機能し、再ログインしても保持される。
- 死亡地点が記録されている間、画面左上に
  `Death: <方角> <度数>° <距離>m  X:<x> Y:<y> Z:<z>` を表示する。
  `<度数>` は現在地から死亡地点への方位磁針の度数表記（0°=北・90°=東・
  180°=南・270°=西）。この行の右端が、バニラのボスバーやHullspark の 
  Coordinate HUD（座標 HUD）が使う画面上部中央の帯にかかるほど長いとき
  は、その帯の下に下げて重ならないようにする（Coordinate HUD 自体も、
  ボスバーが表示されているあいだはさらに下へ下がる）。
- 死亡地点から 3 ブロック以内に近づく（到着）と、その死亡地点を「回収
  済み」として記憶し、その後また離れても表示は出したままにしない。次
  に死んで死亡地点が変わったときだけ再び表示する。この記憶は Fabric の
  config ディレクトリの小さなファイルへ保存するため、ゲームを起動し直
  しても保持される。記憶にはワールド/サーバーの識別(マルチプレイは
  サーバーアドレス、シングルプレイは `saves/` 内の保存フォルダ名。
  ワールド一覧に表示される名前ではない。表示名は新規ワールドが既定で
  「New World」になるなど一意でないため)を添えるため、別のワールド/
  サーバーでたまたま同じ座標で死んでも誤って隠れることはない。ただし
  記憶できるのは常に直近1件のみで、ワールドごとに別々には覚えない(下
  の「既知の制限」参照)。読み書きに失敗してもクラッシュはせず、その
  セッション中はメモリ上だけで動作する。
- 死亡したディメンションと現在のディメンションが異なる場合も、意味の
  ない座標を出さず非表示にする。チェスト・インベントリ・死亡画面・メ
  ニューなど、ほかの画面を開いている間も隠れる（ただしチャット入力中
  は、座標を見ながら打てるよう表示したまま）。
- F1（HUD 非表示）でこの表示も一緒に隠れる。
- 完全クライアント側動作。サーバー通信・自動操作は一切なし。読み取る
  のは、回収コンパスの機能のためにサーバーが既にクライアントへ送って
  いる情報のみ。

## 既知の制限

- バニラの `getLastDeathPos()` と同じく、直近 1 件のみ記録し、履歴は
  保持しない。ローカルに記憶する「回収済み」の記録も同様に、すべての
  ワールド/サーバーを通じて直近1件のみで、ワールドごとに別々には持た
  ない。ワールド A で回収したあとワールド B で別の死亡地点を回収する
  と、A の記録は上書きされる。A に戻ると、その(既に回収済みだったは
  ずの)死亡地点がまた「未回収」として表示される(3ブロック以内に近づ
  けばまた隠れる、通常どおりの動作)。これは既に対処した死亡地点の表
  示が無害に再度出るだけで、新しい死亡が誤って隠れることはない。
- 回収済みの死亡地点と全く同じワールド/サーバー・同じディメンション・
  同じ座標でもう一度死んだ場合、本MODはそれを新しい死亡地点と区別でき
  ない（ワールド・ディメンション・X/Y/Z が完全に一致するため）。その
  ため表示が再び出ず、隠れたままになる。実際にはまれなケースと見込ま
  れるが、シングルプレイのワールドを削除して同じ名前で作り直すと、
  保存フォルダ名も同じ識別に戻るため、このケースに該当しやすくなる。
- マルチプレイでの「同じワールド」判定は接続したサーバーアドレス基準
  のため、実際には同じサーバーでも別のアドレス/ポートで接続すると別
  ワールド扱いになり、片方で回収した死亡地点はもう片方に引き継がれな
  い。逆に、Velocity・BungeeCord 等のプロキシ構成で1つのアドレスの裏
  に複数の実サーバーがある場合は、それらすべてが同じワールド扱いにな
  るため、上記の「同じ座標での再死亡」のケースがより起こりやすくなる。

## 動作要件

- Minecraft Java Edition 1.21.11（Fabric）
- Fabric Loader >= 0.19.5
- Fabric API

ビルド構成は本リポジトリの `mods/sound-subtitle-colors` と同じパターン
（Gradle 9.7.1 + Fabric Loom 1.17.21 の専用 wrapper 同梱。システムの
Gradle 8.14.3 では 1.21.11 向け Loom を解決できないため）。
