# Coordinate HUD（方角・座標 HUD）

Fabric 向けのクライアント専用 MOD。画面上部に「方角（8方位＋度数）・座標
（X Y Z）・ワールドスポーン地点までの距離」を 1 行で表示する。ミニマップ
描画は行わないため、Xaero's 等のマップ系 MOD と機能・ライセンスが競合し
ない。

**AI 支援で作成**: 本 MOD のコードは AI（Claude）の支援で作成した。他
MOD のコードやアセットは一切流用していない。

## 機能

- `<方角> <度数>°  X:<x> Y:<y> Z:<z>  Spawn:<距離>m` を画面上部中央に表示。
  `<度数>` は方位磁針の度数表記（0°=北・90°=東・180°=南・270°=西）で、
  Minecraft 内部の yaw そのままではない。`<距離>` はスポーンまでの
  **水平**（X/Z平面）距離。高さ（Y）は含まない。「歩いてどれだけ離れて
  いるか」を示すのが目的のため、スポーンの真上・真下にいるときは近い
  と表示される。
- 読み取るのはプレイヤー自身の座標・向きと、ワールドのスポーン地点のみ。
  いずれも Minecraft 標準の F3 デバッグ画面で既に見える情報を、常時・コ
  ンパクトに表示するだけ。
- ワールドスポーンが現在と別のディメンション（ネザー・ジ・エンド等）に
  ある場合は、意味のない数値を出さず `Spawn:--` と表示する。
- F1（HUD 非表示）でこの表示も一緒に隠れる。チェスト・インベントリ・
  死亡画面・メニューなど、ほかの画面を開いている間も隠れる（ただし
  チャット入力中は、座標を見ながら打てるよう表示したまま）。
- 完全クライアント側動作。サーバー通信・自動操作は一切なし。

## 未対応（今後の候補）

- プレイヤーが自由に設定できるウェイポイント（現状はワールドスポーンを
  「目的地」の代わりに使用。今後の実装単位の候補）。

## 動作要件

- Minecraft Java Edition 1.21.11（Fabric）
- Fabric Loader >= 0.19.5
- Fabric API

ビルド構成は本リポジトリの `mods/sound-subtitle-colors` と同じパターン
（Gradle 9.7.1 + Fabric Loom 1.17.21 の専用 wrapper 同梱。システムの
Gradle 8.14.3 では 1.21.11 向け Loom を解決できないため）。
