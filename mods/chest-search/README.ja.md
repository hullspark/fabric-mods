# Chest Search（チェスト内検索）

Fabric 向けのクライアント専用 MOD。チェスト・樽・シュルカーボックス・
エンダーチェスト・かまど・ホッパー・ドロッパー・作業台・自分のインベン
トリなど、バニラのコンテナ画面を開いている間に **Ctrl+F** を押すと検索
バーが出る。入力した文字にアイテム名が一致するとそのスロットが緑色に
ハイライトされ、一致しないアイテムは暗く表示される。ツールチップを一つ
ずつ確認しなくても目当てのアイテムを一目で見つけられる。

**AI 支援で作成**: 本 MOD のコードは AI（Claude）の支援で作成した。他
MOD のコードやアセットは一切流用していない。

## 機能

- バニラのコンテナ画面が共通で継承している基底クラス `HandledScreen`
  1 箇所にフックしているため、チェスト・二重チェスト・樽・シュルカー
  ボックス・かまど・ホッパー・ドロッパー・作業台・プレイヤー自身のイン
  ベントリなど、コンテナの種類ごとに個別実装しなくても同じ検索機能が
  動く。
- **Ctrl+F** で検索バーの表示/非表示を切り替える。表示中はタイピング
  するとリアルタイムに絞り込まれ、一致したスロットの背後に半透明の緑
  ハイライトが、アイテムが入っていて一致しなかったスロットには暗い
  オーバーレイが表示される。もう一度 Ctrl+F を押すか **Esc** を押すと
  検索文字列がクリアされ、ハイライトも消える。
- 検索はアイテムの表示名に対する大文字小文字を区別しない部分一致
  （例: `"apple"` で「金のリンゴ」「エンチャントされた金のリンゴ」の
  両方にマッチ、英語名基準）に加え、アイテムのレジストリ ID（例:
  `iron_ingot`）にも部分一致させる。そのため、ゲームの表示言語が日本
  語など英語以外でも、`"iron"` のような半角の英単語でそのアイテムを
  探せる。検索語に空白を含む場合（例: `"iron ingot"`）は、ID との照合
  では空白を `_` として扱う（`iron_ingot` にマッチ）。
- 検索バー表示中はキー入力を検索側で消費するため、絞り込みのために
  数字キーを打ってもバニラのホットバー入れ替え・クイック移動が誤発動
  しない。
- 完全クライアント側動作。サーバー通信・自動操作は一切なし。アイテム
  を動かしたり取得したりすることは一切なく、既に画面に表示されている
  情報を読んでオーバーレイを描画するだけなので、サーバー側がチートと
  みなす余地のある機能ではない。

## 既知の制限

- クリエイティブモードのインベントリでは意図的に本MODを無効化してい
  る。クリエイティブは既にバニラ標準の検索タブを持っており、タブ切替
  用のホットキー（"t" 等）が本MODの検索入力と衝突するため。
- 文字入力は実際の文字入力イベントを使っているため、US配列以外の
  キーボード配列にも追従するはず。IME（日本語入力など）による変換入
  力自体はこの検証環境（ディスプレイなし）ではテストできておらず、
  実際に日本語で入力して検索できるかは未確認。0.1.1 の実機確認では、
  表示言語が日本語のとき半角の英単語 `"iron"` が何にも一致しなかった
  （表示名しか見ていなかったため）。0.1.2 で ID 一致を追加したため、
  表示言語によらず同じ検索語で見つかる（2026-09-29 に、表示言語を
  日本語にした実機で確認済み）。
- Ctrl+F のみ対応。macOS の Cmd+F では反応しない。

## 動作要件

- Minecraft Java Edition 1.21.11（Fabric）
- Fabric Loader >= 0.19.5
- Fabric API

ビルド構成は本リポジトリの `mods/sound-subtitle-colors` と同じパターン
（Gradle 9.7.1 + Fabric Loom 1.17.21 の専用 wrapper 同梱。システムの
Gradle 8.14.3 では 1.21.11 向け Loom を解決できないため）。
