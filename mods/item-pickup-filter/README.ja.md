# Item Pickup Filter（アイテム自動拾いフィルター）

指定したアイテム（既定では腐った肉・毒入りジャガイモ・クモの目）を自動
で拾わないようにする、小さな Fabric MOD。戦闘や採掘中にインベントリが
不要品で埋まるのを防ぐ。

**AI 支援開発の開示**: 本 MOD のコードは AI（Claude）の支援を受けて書か
れています。他の MOD のコードやアセットは流用していません。

## 機能

- `config/item-pickup-filter.json`（初回起動時に既定値で自動生成）に
  登録したアイテム ID の拾得だけをキャンセルする。それ以外はバニラどお
  り拾える。
- 対象アイテムは地面に残るだけで、消滅はしない。設定からその ID を削除
  して再起動すれば、また普通に拾えるようになる。
- キー割り当て・HUD・コマンドは無し。設定ファイルを編集して再起動すれ
  ば反映される（起動時にのみ読み込む）。

## 設定方法

`config/item-pickup-filter.json` を編集する。

```json
{
  "blacklist": [
    "minecraft:rotten_flesh",
    "minecraft:poisonous_potato",
    "minecraft:spider_eye"
  ]
}
```

`/give` と同じ形式のアイテム ID（例: `minecraft:gunpowder`、他 MOD のア
イテム ID も可）を追加・削除する。形式が不正な ID は警告ログを出して読
み飛ばし、残りのリストはそのまま適用される。起動時にレジストリと照合し
て解決するのではなく ID の名前で直接比較する方式のため、他 MOD のアイ
テム ID を指定しても MOD の読み込み順に左右されず正しく機能する。ファ
イル自体が無い・壊れている場合は既定値にフォールバックし、起動に失敗す
ることはない。

## どちら側でフィルタされるか

バニラの拾得判定はワールドロジックを実行している側（サーバー）が権威を
持つ。

- **シングルプレイ**: 統合サーバーがクライアントと同一プロセスで動くた
  め、MOD を入れるだけでそのまま機能する。
- **専用マルチプレイサーバー**: **サーバー側**に導入する。拾得の判定自
  体はサーバー側で行われるため、プレイヤー側の導入は必須ではない（ただ
  し MOD 一覧を揃える意味でクライアントにも入れるのが一般的）。
- MOD を入れていないサーバーに、**クライアントにだけ**このMODを入れて
  接続した場合は拾得判定はサーバー側の権威に従うため、フィルタは効かな
  い（実害は無く、単に無効なだけ）。

Minecraft 1.21.11 向け。Fabric Loader が必要（Fabric API への依存は無し）。
